## What I've been building

Most of my recent work is commercial code for AireStream and its clients, so those repositories are private. Happy to walk through any of them on a call.

- **Multi-agent system:** about a dozen scheduled LLM agents that read call transcripts, CRM data and replies, then draft follow-ups, call sheets and content. Every output passes schema validation and code guardrails before landing in a human approval queue. Facts pulled from transcripts must carry a quote that is checked word for word against the source.
- **Live AI visibility tool:** scores a website with Claude and runs a live ChatGPT web-search test inside a 26-second serverless budget, with caching, hard timeouts and fallbacks.
- **LLM evaluation:** a multi-engine test harness (buyer questions across ChatGPT, Claude, Gemini, Copilot and Perplexity) with a shared, tested brand-mention detector and before-and-after re-tests.
- **Client portal:** Django and React app fed by our internal platform over a signed API bridge, with per-request access checks.
- **Athlete performance platform:** client build in Next.js and Supabase with row-level security, automated GPS file parsing and AI-drafted reports that publish only after analyst approval.
